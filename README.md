# HealthOva – Mindfulness Landing Page 💜

A modern and responsive mindfulness website landing page built using **HTML, CSS, and JavaScript**.

### ✨ Features
- Clean and modern UI design
- Glowing and hover effects
- Smooth scroll animations
- Animated statistics counter
- Interactive navigation bar
- Responsive layout

### 🛠️ Technologies
- HTML5
- CSS3
- JavaScript

### 🚀 Getting Started
1. Clone this repository.
2. Open the project folder in VS Code.
3. Run `index.html` using Live Server.

### 📁 Project Structure
```text
Mindaro/
├── index.html
├── style.css
└── script.js
```
